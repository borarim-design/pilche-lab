# 필체연구소 v2.0 — 아이패드 가이드와 한글 조합

## iPad에서 바로 시작

Safari에서 https://borarim-design.github.io/pilche-lab/?v=2#guide 를 엽니다.

1. 가이드 선택에서 필수 자음 1·2와 필수 모음 1·2를 차례로 작성합니다.
2. 빈 칸에 Apple Pencil로 크게 씁니다. 각 획을 마치면 자동 저장됩니다.
3. 손바닥 입력을 막으려면 ‘Pencil로만 쓰기’를 켭니다.
4. 기본 필체 33/33을 채운 뒤 손글씨 스튜디오에 원하는 문장을 입력합니다.
5. 직접 등록하지 않은 현대 한글은 내 자음·모음으로 조합됩니다. 겹모음 7종과 겹받침도 지원합니다.
6. 선택 가이드의 완성 글자도 쓰면 해당 글자는 조합보다 우선 사용됩니다.
7. PNG로 저장하거나 내 글씨 백업(JSON)을 내려받습니다.

이 버전은 앱 안에서 쓰는 비트맵 필체 조합기입니다. TTF/WOFF 파일을 내보내거나, AI가 실제 필체와 동일한 글자를 생성하는 기능은 없습니다. 같은 자음도 초성·받침·모음 위치에 따라 실제 필기 모양이 달라지므로 조합 결과와 원래 필체에는 차이가 있습니다. 숫자·영문·문장부호는 별도 등록이 필요하며 부족한 글자는 기본 글꼴과 밑줄로 표시합니다. 미리보기에는 직접 작성·조합·기본 글꼴의 글자 수가 나옵니다.

브라우저에서 필기·자동 저장·새로고침 복구·가/각 조합·PNG 다운로드를 확인했습니다. Unicode 현대 한글 11,172자 전체의 구성요소와 렌더링 배치 규칙을 검사했습니다. 물리적 iPad/Apple Pencil 하드웨어 검증은 아직 수행하지 않았습니다.

아래는 기존 종이 사진 등록 방식의 사용법입니다.

종이 가이드에 직접 쓴 손글씨를 촬영하고, 글자를 분리하여 웹 문장에 적용하는 **AI API 없는 브라우저 기반 앱**입니다.

## 빠르게 시작하기

1. 이 ZIP을 풀고 `index.html`을 브라우저로 열어보세요.
2. 가이드 용지 `손글씨_가이드용지_3장.pdf`를 **A4 / 실제 크기(100%)**로 인쇄하세요.
3. 각 칸 왼쪽 위에 있는 연한 글자를 보고, **칸 가운데 아래쪽에 검은 펜으로** 크게 써주세요.
4. 네 모서리의 **검은 정렬 마커 4개**가 모두 보이게 각 페이지를 촬영하세요.
5. 웹앱에서 1번, 2번, 3번 용지 사진을 각각 업로드하세요.
6. 사진에 표시된 네 검은 마커의 **중앙**을 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래 순서로 클릭하거나 터치하세요.
7. 빨간 격자가 손글씨 칸과 일치하는지 확인하고 '이대로 글자 추출하기'를 누르세요.
8. '손글씨 스튜디오'에서 텍스트를 작성하고 'PNG로 저장'을 누르세요.

종이를 출력하기 전에 동작을 테스트하고 싶다면 `샘플_작성용지_1번.png`를 웹앱 **첫 번째 용지**에 업로드할 수 있습니다. 예제 이미지는 사용자의 필체가 아니라 테스트용 글씨입니다.

## 추천 실행 방법

`index.html`을 직접 더블클릭해도 대부분의 브라우저에서 실행할 수 있지만, 파일 URL에서는 저장 권한과 일부 기능에 제약이 있을 수 있습니다. 개발 중에는 이 폴더에서 아래 명령으로 로컬 서버를 켜는 편이 안정적입니다.

```bash
python3 -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000`을 엽니다. HTTPS를 지원하는 정적 호스팅(GitHub Pages, Vercel, Netlify 등)에 폴더 내용을 배포하면 모바일 브라우저에서도 사용할 수 있습니다. 설치형 PWA 모드는 HTTPS 또는 localhost 환경에서 지원합니다.

## 현재 지원 기능

- iPad Safari의 Apple Pencil·손가락 포인터 입력
- 3장/243칸의 정해진 가이드 PDF
- 사진의 4점 원근 보정 (마커는 **사용자가 직접 지정**)
- 칸별 글자 추출 및 배경 제거 (OCR 및 외부 AI 호출 없음)
- 글자 크기, 간격, 흔들림, 잉크 색상, 배경 선택
- 입력 문장을 1150×730 픽셀 PNG로 저장
- 미등록 글자는 드로잉 패드에서 추가
- 브라우저 IndexedDB 저장 및 JSON 백업/복구
- 반응형 디자인 / PWA 기본 설치 및 오프라인 캐시

## MVP의 명확한 한계

사진으로 등록한 글자는 원본 글자 이미지가 우선 사용됩니다. 가이드 자모가 모두 등록된 한글은 자모를 조합하며, 필요한 자모가 부족하면 기본 시스템 폰트와 밑줄로 표시됩니다. 손글씨의 모양과 크기는 정규화됩니다.

사진의 밝기, 그림자, 원근, 펜 색에 따라 인식 정확도가 달라집니다. 검은 펜과 밝고 고른 조명을 권장합니다. 잘못 추출한 글자는 '미등록 글자 직접 추가' 기능으로 덮어쓰거나 페이지를 다시 업로드할 수 있습니다.

## 데이터 및 개인정보

업로드 사진과 추출된 글자는 외부 서버로 전송하지 않습니다. 추출·편집 로직은 브라우저에서 실행되고, 글자 이미지는 현재 브라우저의 IndexedDB에 저장됩니다. 기기 교체, 브라우저 초기화, 시크릿 모드에서는 데이터가 사라질 수 있으므로 **내 글씨 백업(JSON)** 파일을 내려받으세요.

## 파일 구조

- `index.html` / `styles.css`: 화면
- `app.js`: 사진 정렬, 글자 추출, 글씨 출력, 저장 및 편집 기능
- `손글씨_가이드용지_3장.pdf`: 인쇄할 용지
- `샘플_작성용지_1번.png`: 업로드 테스트용 샘플 (실제 손글씨 아님)
- `glyph-layout.json`, `make_template.py`: 가이드 용지 생성 소스
- `manifest.webmanifest`, `sw.js`, `icon-*.png`: PWA 설치와 오프라인 자산

외부 라이브러리, AI API 키, 백엔드는 필요 없습니다.
